# ИИ-ассистент по размещению Синоникса

Веб-приложение для предварительного проектирования размещения программно-аппаратного комплекса «Синоникс» компании «АйТи Бастион». Проводит пользователя от свободного описания двух сетей и потоков обмена к обоснованной схеме, таблице минимально необходимого числа правил, редактируемому файлу .drawio и служебному JSON для экспертной проверки.

Бекенд ожидает OpenAI-совместимое API ИИ-модели на localhost:8080. ИИ-модель запущена на домашнем компьютере с видеокартой с 16 GB видеопамяти. Удаленный доступ к домашнему компьютеру осуществляется через Hysteria2 и доступен только разработчикам данного репозитория, поэтому если вы запустите фронтенд и бэкенд, вам нужно будет пробпросить API какой-либо нейросети на порту 8080. Hysteria2 была выбрана для наибольшей скорости сети в условиях нестабильного интернета.

Запуск фронтенда
```bash
docker compose up -d frontend
```

Запуск бэкенда
```bash
docker compose up -d backend
```

Контейнер для запуска LLM предназначен для видеокарт AMD с 16GB и более видеопамяти.

Запуск LLM
```bash
cd llm
docker compose up -d
```

`backend/` - бэкенд
`fronend/` - фронтенд
`llm/`- ИИ-модель в своем Docker-контейнере
`hysteria/` - конфиги клиента и сервера Hysteria2
